# 2026-10-22 蓝牙架空速度环调参记录

> 历史架空调试记录，其中暂定增益已被后续落地配置替代，当前状态见 [交接文档](../HANDOFF.md)。

本文保留早期架空试验的历史结果。随后落地调参已更新默认值，当前结论见 [落地记录](GROUND_TEST_RESULT.md)，请勿将本文的 0.5/1.5/0 当作当前源码默认值。

用户确认两轮架空、可自由转动后，通过 COM7/9600 与实际固件双向通信。开始时先发送停止并读取配置；每次试转有板端截止时间、350 ms 心跳，结束后接收待机且双轮请求输出为零的速度帧。未进行落地负载测试。

## 暂定结果

左右轮均为 `Kp=0.5、Ki=1.5、Kd=0`，速度上限 1000 counts/s，输出上限 700（70%）。最终通过配置回读确认已在线应用，并确认停止；`main.c` 的上电默认配置和 `tools/speed_pid_tuned.json` 已同步。在线参数在 RAM 中，断电保持仍需烧录此次更新的默认值。

这是当前架空条件下的暂定选择，不声称最优；此前参数已比较接近可用，本轮改善有限。10 ms 编码计数在该速度下分辨率约为 100 counts/s，遥测仅 5 Hz，不能从这些采样证明内部 100 Hz 控制无振荡。左右电机静摩擦、供电及负载差异会影响实际表现。

## 实测比较

稳态统计排除启动后前 2 秒，只使用运行状态帧。标准差和平均绝对误差基于遥测瞬时速度，均值也不等同于整段累计计数测得的真实平均速度；采样混叠与量化会影响统计。各试验不同时，未随机排序，不宣称统计显著性。

| 试验 | 目标 | 左/右平均速度 | 左/右标准差 | 左/右平均绝对误差 | 左/右采样峰值 |
|---|---:|---:|---:|---:|---:|
| 原参数 2.5 / 1.5 / 0，8 秒 | 500 | 539.74 / 534.94 | 72.99 / 59.31 | 63.48 / 47.84 | 700 / 600 |
| 暂定参数 0.5 / 1.5 / 0，首次 10 秒 | 500 | 539.68 / 536.61 | 58.12 / 62.75 | 51.68 / 48.61 | 600 / 700 |
| 暂定参数复测，10 秒 | 500 | 547.20 / 518.17 | 62.69 / 62.17 | 51.29 / 37.68 | 700 / 800 |
| 暂定参数换目标，10 秒 | 800 | 844.39 / 822.85 | 60.27 / 61.12 | 52.83 / 39.93 | 1000 / 1000 |

速度及误差单位为 counts/s。最终参数不保证均值偏差消失，也不保证所有速度下都优于原参数。输出未达到配置的 700 上限，因此本轮没有提高输出限幅。

## 其他候选与排除原因

- `Kp=1.8、Ki=1.5`：左轮误差较原参数有所减小，右轮波动未稳定改善。
- `Kp=1.0、Ki=1.5`：左轮波动较大，没有一致优势。
- `Kp=0.2、Ki=1.5`：稳态均值更接近目标，但启动采样峰值达左 1200、右 1500，不采用。
- `Kp=0.2、Ki=0.5`：右轮达 1600，触发试验程序异常速度保护，立即发送停止并收到待机零输出验证帧，提前中止，不采用。
- `Kp=0.8、Ki=0.5` 及 `Kp=1.5、Ki=0.5`：可运行，但稳态误差没有全面改善。
- 左轮独立降到 `Kp=0.35、Ki=1.5`：没有进一步改善，左启动峰值到 900，因此恢复 0.5。
