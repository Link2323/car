# 串口调试与固件调参协议

人工调试使用 VOFA 或其他串口工具观察数值帧；自动调试按下面协议编写短脚本即可。项目不再维护自制电脑界面，也未保留可直接运行的自动试车脚本。固件的在线调参、定时试转、停止和标定接口继续保留。

## 连接与收帧

接手者在设备管理器确认当前小车的 USB 串口设备或 HC05 对应的蓝牙串口，连接参数为 **9600、8N1**。更换电脑后重新识别端口，不照搬历史 COM 号。串口同一时间只由一个工具占用，脚本与 VOFA 不同时打开同一端口。

遥测为带标签的 FireWater 数值帧，每行以 LF 结束：

```text
speed:状态,故障,左目标,右目标,左实测,右实测,左请求占空比,右请求占空比
enc:标定模式,左累计,右累计,采样有效,累计有效,时间戳ms
head:数据有效,积分有效,z角度
mpu:初始化,校准,读取,0x68探测,0x68身份,0x69探测,0x69身份
maze:状态,决策,左mm,前mm,右mm,感知有效,航向基准x100,直行ms,决策数
```

各帧由 `main.c` 顶部宏独立开关。**当前默认仅输出 `head:`**（速度环联调时再打开 `SPEED_DEBUG_TELEMETRY_ENABLE`，`head:` 全零排查时打开 `MPU_DEBUG_TELEMETRY_ENABLE`，需要轮程时打开 `ENCODER_TELEMETRY_ENABLE`，均需重新编译烧录）。

`speed:` 约 5 Hz，速度单位 counts/s，占空比为千分比；状态为 0 待机、1 运行、2 故障。故障为 0 无、1 编码反馈、2 电机接口、3 非法目标。累计计数保留有符号 64 位。`head:` 约 5 Hz，为陀螺仪 z 轴积分角度（航偏角）：单位度，直接输出两位小数的真实值，串口工具无需换算；数据有效取自最近一次读取是否成功，积分有效表示已建立时间基准。积分间隔超过 200 ms 的样本不参与积分，只刷新基准；角度未经融合修正会缓慢漂移（实测约 0.8 度/分钟）。左转（俯视逆时针）为正角度。`mpu:` 约 1 Hz，为陀螺仪上电诊断：前三个字段为初始化、零偏校准、最近读取的 HAL 状态（0 成功、1 错误、2 忙、3 超时），后四个为 0x68/0x69 两地址的探测状态与读到的 WHO_AM_I 身份；`head:` 全零时先看该帧定位失败环节（读取持续为 2 表示数据就绪从不置位，身份非 0x68/0x70 表示应答的是不支持的其他芯片）。具体曲线显示按所用工具配置；接收时区分不同标签及各自字段数量，不把配置回执混作速度样本。物理单位换算见 [编码器标定](ENCODER_CALIBRATION.md)。

## 命令与回执

上电后等收到遥测，再发送 `tune:1` 并附 LF 或 CRLF，即可快捷启动左手迷宫寻路。成功回复 `ack:1,11,0`；运行中或故障锁存时回复状态 2，不重启当前任务；陀螺仪未就绪等错误回复状态 1。停止仍使用完整命令，例如 `tune:100,3`，下一条新事务使用新编号。故障后先停止清障，再发送 `tune:1`。

快捷命令必须精确为 `tune:1`，不占用完整协议的事务号 1；成功启动时旧事务缓存失效，避免再次发送旧停止命令时只回放成功回执。停止后可以再次发送相同快捷文本。该快捷命令保持所有启动条件与保护，不在上电时自动启动，不需要心跳。

ASCII，每条命令以 LF 结束，可兼容 CRLF，最长 127 字节。普通事务号 `id` 为 1～2147483647，每条新命令使用新编号，逐条等待匹配回执。固件只缓存最近一次事务，相同的重复命令不会重复启动或延长任务，不能当作完整重试机制。心跳固定使用编号 0，不回复。

| 命令 | 含义 | 成功回复 |
|---|---|---|
| `tune:id,0` | 读取配置 | `cfg:id,...` |
| `tune:id,1,Lkp,Lki,Lkd,Rkp,Rki,Rkd,maxSpeed,maxDuty` | 应用完整配置 | `cfg:id,...` |
| `tune:id,2,left,right,durationMs` | 从待机启动定时试转 | `ack:id,2,0` |
| `tune:id,3` | 停止并清控制故障 | `ack:id,3,0` |
| `tune:0,4` | 保持运动心跳 | 不回复 |
| `tune:id,5,left,right` | 更新当前任务目标，不延长任务 | `ack:id,5,0` |
| `tune:id,6` | 停机、进入标定并清累计基线 | `cal:id,...` |
| `tune:id,7` | 标定中读取累计计数 | `cal:id,...` |
| `tune:id,8` | 退出标定，保持禁用 | `cal:id,...` |
| `tune:id,9` | 清零陀螺仪角度积分 | `ack:id,9,0` |
| `tune:id,10,angle` | 陀螺仪闭环转向（正角左转、负角右转，±360 内非零；如 90、-90、180） | `ack:id,10,0` |
| `tune:id,11` | 启动左手法则迷宫探索（反应式，见 maze 模块说明） | `ack:id,11,0` |

六项增益均乘 10000 编码，速度为整数 counts/s，输出限幅为千分比。例如当前暂定参数的配置回读内容为：

```text
cfg:id,8000,15000,0,6000,15000,0,2100,700
```

失败回复 `ack:id,op,status`，HAL 状态为 0 成功、1 错误、2 忙、3 超时；无法解析的帧回复 `ack:0,0,1`。标定回复为 `cal:id,标定模式,左累计,右累计,采样有效,累计有效,时间戳ms`。命令 10 转向不要求心跳：以启动时刻 z 角度为基准计算绝对目标，误差进入 2 度并保持 300 ms 判定到位自动停机；超时（约 3 s + 每度 30 ms）或陀螺仪数据失效（200 ms 无新样本）时停机并锁存故障，需 `tune:id,3` 停止或清障后再启动。转向进行中命令 5 与命令 9 被拒绝，避免目标冲突。命令 11 迷宫探索同样不要求心跳：反应式左手法则（左开走左，否则直行，再否则右转，全堵掉头），判墙阈值 180 mm、前方停车 60 mm（实测迷宫格宽约 200 mm，贴墙停以检测墙角开口），直行带 z 航向保持；左口确认后先按轮程前滑约 60 mm 到开口中部再停车左转，前墙与单段直行 8 s 超时立即停车重新决策；前方指定的新鲜无回波允许约 20 mm/s 低速探测；通信故障、超时、其他前向错误和左右测距无效立即保护停机锁存 FAULT，`tune:id,3` 清障后可再启动。探索中命令 2/5/9/10 均被拒绝。`maze:` 约 1 Hz：状态 0 待机、1 决策、2 转向、3 直行、4 左口滑行、5 故障；决策 0 无、1 左、2 直、3 右、4 掉头；感知有效为位掩码（1 前、2 左、4 右）。

## 人工与脚本调试流程

先收帧确认设备，再发送停止和配置读取。例如发送 `tune:1,3`、等待对应回执，再发送 `tune:2,0` 并检查 `cfg:2,...`。这些命令都要附换行。当前最高速度仍需按 [交接文档](../HANDOFF.md) 实测确定，200 mm/s 已出现后仰，不作为通过档位。

运动命令另行显式发送，定时时长范围为 100～30000 ms。运动期间每约 400 ms 发送一次 `tune:0,4`；超过 1500 ms 无心跳，固件停机。因此只用串口工具手动发送一次启动而不持续心跳，任务可能提前停止。人工工具如需持续试转，应配置周期心跳发送；否则使用能处理回执和心跳的短脚本。转向命令 10 已封装为 `tests/turn.ps1`：`pwsh tests/turn.ps1 left90|right90|uturn|stop [-Port COM14]`，自动完成链路确认、清障、下发命令并汇报转角误差。

脚本应设置有限运行时长及接收超时，遇到控制故障、遥测失联或异常速度就停止试验；异常和退出路径尽力发送停止并关闭串口。发送停止不等于已经停稳，需继续确认待机、双轮实测速度和请求输出均为零。自动化不能通过编码器均速判断是否后仰，机械姿态仍需现场观察。试车期间不暂停 MCU 调试器。

心跳、定时和反馈超时保护依赖主循环，不提供独立硬件急停。在线配置仅在 RAM 生效；确定最终最大速度后同步 `main.c` 和 `speed_pid_tuned.json`，重新编译、烧录并回读确认。

## 2026-11-12 测距恢复与寻路保护

同日后续适配前向模块朝上、远处矮墙无回波的安装条件：仅当前路返回新鲜（不超过 200ms）的 `RANGE_INVALID`，原始距离为 8190 且原始状态码为 6 或 9 时，允许每轮最多 400 counts/s（约 20 mm/s）低速探测；该状态不代表已确认前方没有墙。前路实际有效距离仍按原 60mm 阈值停车，已检测到停车线内的近墙会保留至改变方向，不会被后续无回波抹除。通信错误、超时、过期数据及其他错误仍停机，左右必须保持有效。`tof:` 有效掩码保持真实值，因此 `maze:` 运行时可见前距 0、有效掩码 6，不能再仅凭掩码 6 判断寻路故障。左手优先与原有单段超时不变。

同日已修改三路 XSHUT：关断为开漏拉低，释放切为输入上拉，启用 STM32F1 内部弱上拉；上电 GPIO 仍默认保持低电平。软件上拉版已烧录并比对 Flash，ST-Link 连续 6 次回读三路均有效，右路 145～147 mm，PB5 输入为高。验证时速度环、转向、迷宫均待机，四路 PWM 输出为零；尚未进行该版本的落地寻路验收。

寻路仍为左手优先。测距通信错误或超时关闭该路后，仅在速度环待机、无寻路或转向任务时，每隔至少 2 秒重新初始化故障路，连续最多尝试 3 次；其他两路不复位。收到有效回波后重置预算。无目标、超量程等无效回波不会被当成可通行距离。

直行、左口前滑及寻路转向期间，除上述前路无回波特例外，感知异常均停车并锁存故障。故障后恢复读数不会自动恢复行驶；确认感知满足启动条件后先发新的停止清障命令，再发新的启动命令。三次恢复仍失败时需检查原因并复位，重置尝试预算。

新增诊断帧约 1 Hz，保留原 `tof:` 七字段格式：

```text
tofdiag:前状态,前HAL,前原始状态,左状态,左HAL,左原始状态,右状态,右HAL,右原始状态
```

测距状态：0 正常、1 初始化失败、2 I2C 错误、3 超时、4 回波无效、5 等待首帧；HAL 状态：0 成功、1 错误、2 忙、3 超时。正常回波原始状态为 11，尚未取得结果为 255。
